# Kimi K3 / GMI Cloud UIレビュー実行記録

実行日: 2026-07-25

## 結果

- GMI Cloudの認証済み `/v1/models` で
  `moonshotai/kimi-k3` が利用可能であることを確認した。
- ai&のモデル一覧にはKimi K3はなく、Kimi系は
  `moonshotai/kimi-k2.7-code` だったため、K3はGMIを選択した。
- UIレビューは1回5セント上限、同時実行1、自動再試行なしで2回まで試行した。
- 1回目は応答のusageを確定できなかった。ユーザーの明示許可後、
  予約上限の5セントを全額使用済みとして保守的に精算した。
- 2回目はHTTP 400で失敗した。usageが得られなかったため、この予約も
  上限の5セントを全額使用済みとして扱った。
- 同じ失敗への3回目は行っていない。Kimi K3のモデル提供は確認できたが、
  UIレビュー本文は取得・採用できなかった。

## 安全設定

- モデル: `moonshotai/kimi-k3`
- 予約上限: USD 0.05 × 2回（合計USD 0.10を保守的に使用済み扱い）
- 自動課金追加: 無効
- 有料フォールバック: 無効
- 自動再試行: なし
- ガード台帳: `.guard/`（Git管理外）

このため、公開UIの採否はClaude Code Opus 5の設計、
決定論ルール、TypeScript/Vitest/Playwright、実画面確認を根拠にする。
