# Claude Code Opus 5 日本語UI再設計

2026-07-25、Claude Code CLI `2.1.196` の正確なモデル
`claude-opus-5` を読み取り専用で実行し、日本語中心の情報設計を再検討した。

## 中心価値

> お店に電話しなくても、入口の段差・幅・筆談の様子を、行く前に自分の目で確かめられます。

## 採用した主要コピー

- 撮影: 「お店の入口を撮ると、行く前に分かる案内になります。」
- 補足: 「20秒の動画から、段差・入口の幅・通路・筆談などをAIが整理します。分からない所は『未確認』のまま残します。」
- 操作: 「動画から情報をつくる」
- 確認: 「公開前に、お店の方が確かめてください。」
- 公開: 「{店名} 来店前アクセス案内」

## 情報の見せ分け

- AI観察
- AI参考推定（必ず幅付き、実測ではない）
- スタッフ確認済み
- 未確認

「車椅子で利用可能」「バリアフリー対応」のような包括認定は避ける。
車椅子、ベビーカー、白杖・見えにくさ、筆談、段差、入口幅の6分類に、
具体情報が掲載されているかを表示する。

## 画像設計

ChatGPT Images 2.0で6分類のピクトグラム原画を生成し、認証バッジに
見えない平面表現として使う。動画から自動抽出した同じ時刻付き画像を
Qwen VLの入力、店舗確認、公開ページの根拠に一貫して利用する。
